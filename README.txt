SALYQFLOW — папка для загрузки на хостинг

Что внутри
  index.html      главная страница (лендинг)
  app/index.html  само приложение (кабинет)
  privacy.html    политика конфиденциальности (черновик)
  terms.html      условия использования (черновик)
  style.css       общий стиль страниц

Как выложить (Cloudflare Pages, Netlify или GitHub Pages)
  1. Зарегистрируйтесь на выбранном хостинге.
  2. Создайте новый сайт и загрузите ВСЮ эту папку целиком (или zip-архив).
  3. Через пару минут получите адрес сайта. Главная страница откроется по нему,
     кабинет по адресу /app/.
  4. Свой домен подключается в настройках хостинга, пункт «Custom domain».

Что заполнить до публичного запуска
  В privacy.html и terms.html найдите места на жёлтом фоне и замените:
    ДАТА, ВАШЕ ИМЯ / НАЗВАНИЕ ИП, ВАШ EMAIL, НАЗВАНИЕ ХОСТИНГА
  Затем покажите оба документа юристу и удалите жёлтую плашку «Черновик».
  Без заполненных контактов страницы выкладывать нельзя.

Важно
  Кабинет хранит данные в браузере пользователя. Другой телефон или очистка
  браузера означают потерю данных. Настоящий вход с любого устройства,
  вход по ЭЦП и автоматические напоминания появятся только с сервером.
