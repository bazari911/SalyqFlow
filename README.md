# SALYQFLOW

Личный кабинет для ИП на упрощённой декларации в Казахстане. Читает PDF-выписки Kaspi, Halyk и Банка ЦентрКредит, отделяет доход от кредитов и своих денег, считает налог за полугодие и напоминает о сроках.

> **Статус: прототип.** Расчёты справочные и не заменяют налоговый кабинет и бухгалтера. Приложение не подаёт декларации, не проводит платежи и не подключено к государственным системам, ЭСФ и банкам.

## Что умеет

- **Чтение PDF-выписок** Kaspi, Halyk и ЦентрКредит прямо в браузере. Файлы никуда не отправляются.
- **Классификация поступлений:** доход, кредит или заём, свои средства, пополнение наличными, возврат или ошибка.
- **Сверка с банком:** сумма разобранных операций сравнивается с итогами, напечатанными в самой выписке.
- **Проверка спорных операций:** программа показывает, в чём не уверена, а ваши решения попадают в журнал с причиной.
- **Налог по полугодиям:** ставка задаётся при регистрации, для отдельного полугодия её можно изменить.
- **Блок «Оплатить налог»:** сумма, срок, плательщик и ИИН, которые можно скопировать для банка.
- **Налоговый календарь и социальные платежи:** сроки, расчёт ежемесячных взносов, отметка «оплачено».
- **Напоминания:** добавление срока в Google Календарь, файл `.ics`, отправка текста в Telegram и WhatsApp.
- **Подсказки простым языком:** например, почему кредит не считается доходом.
- **Сводка для бухгалтера:** Excel с итогами по периодам, всеми поступлениями и журналом решений.
- **Регистрация и вход по ИИН:** проверка ИИН (в том числе контрольной цифры), дата рождения берётся из него, пароль не короче 8 символов с заглавной и строчной буквой, цифрой и спецсимволом.

## Как это работает

Приложение написано на чистом HTML и JavaScript, без сборки и без сервера.

1. Для чтения PDF страница подгружает библиотеку [pdf.js](https://mozilla.github.io/pdf.js/) с CDN.
2. Текст выписки разбирается по колонкам таблицы каждого банка, строки привязываются к датам операций.
3. Сумма разобранных операций сверяется с итогами банка.
4. Поступления классифицируются по коду назначения платежа (КНП), тексту назначения и ИИН владельца счёта.
5. Налог считается как `доход × ставка` за каждое полугодие.

## Запуск

Откройте `index.html` в браузере или выложите папку на любой хостинг статических сайтов (Cloudflare Pages, Netlify, GitHub Pages). Кабинет находится по адресу `/app/`.

Для первого чтения PDF нужен интернет: библиотека pdf.js загружается из сети.

## Данные и приватность

- Кабинет, пароль (в виде хеша) и строки поступлений хранятся **только в браузере на вашем устройстве**.
- Сами PDF-файлы не сохраняются.
- Если очистить данные браузера или сменить устройство, кабинет не перенесётся.
- Забытый пароль сбрасывается по ИИН и телефону, указанным при регистрации. Это демо без сервера: SMS не отправляется.

Подробнее в [политике конфиденциальности](privacy.html) и [условиях использования](terms.html). Оба документа пока черновики, их нужно проверить юристу до публичного запуска.

## Ограничения

- Поддерживаются только выписки Kaspi, Halyk и ЦентрКредит в формате PDF. Формат выписок банков может измениться, тогда чтение придётся обновить.
- Ставка налога вводится вручную. Ставку для своего района нужно подтвердить по решению маслихата.
- Сроки и ставки социальных платежей взяты из открытых источников и требуют сверки в кабинете налогоплательщика.
- Автоматические сообщения в Telegram и WhatsApp не отправляются: для этого нужны сервер и бот.
- Вход по ЭЦП и eGov невозможен без серверной части.

## Планы

- Серверная часть: вход с любого устройства, хранение данных на серверах в Казахстане.
- Справочник налоговых ставок по районам.
- Автоматические напоминания в Telegram.
- Вход по ЭЦП.
- Другие банки.

## Отказ от ответственности

Все суммы, ставки, сроки и классификация поступлений носят справочный характер и не являются налоговой, бухгалтерской или юридической консультацией. Перед подачей декларации и уплатой налога сверьте данные в официальных источниках.
